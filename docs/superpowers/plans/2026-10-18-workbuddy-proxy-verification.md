## 实现

- `npm run browser:install` 下载到项目 `.local-browsers/`，当前为 Chromium 1248；不启动用户日常 Edge/Chrome。缺失安装时在账号占用及远端请求之前报错。
- 配置支持直连、HTTP/HTTPS 代理认证、无认证 SOCKS5。代理配置加密落盘，密码不回传；相同地址/用户名留空保留，修改端点/用户名需重填，直连保存清除代理。
- 配置 revision、任务期间配置锁、旧目标迁移保持兼容。API 连接测试及远端请求不使用浏览器代理。
- 缺少 GitHub 入口、导航网络错误、代理连接错误分别给安全提示，不输出原始错误/URL/密码，不推断 IP 风控。
