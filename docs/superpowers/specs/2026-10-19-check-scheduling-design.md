# PAT 随机接续与自动检测方案

状态：用户已确认，功能已实现并验证；自动检测默认关闭，等待用户选择范围和周期后启用。

## 目标与现状

- 每次新检测任务（单个、勾选、筛选、全部、定时）随机选择一个可用 PAT，任务内持续使用，普通配额不足时接续其他有额度的账号。
- 根据每个账号最近检测时间判断是否到期，只检测符合筛选条件的账号。
- 配置通过一个紧凑弹窗完成，不增加常驻大卡片或操作记录页面。
- 当前 checker 已有持久化进度和恢复能力；PAT 按数据库顺序选择，普通额度耗尽也写入全局冷却。账号已有 checkedAt、分组、标签和公开检测状态。

## PAT 选择与接续

1. 新任务随机打乱合格 PAT 账号顺序；单个账号检测也是一个独立任务。同一任务保持当前 PAT，恢复任务不重置已完成进度。随机允许相邻任务碰巧使用同一账号。
2. 仅选择已验证、未停用、未过期且不在冷却中的凭据；按 GitHub 账号识别额度，不能将同一账号的多条 token 视为独立额度。
3. 普通额度耗尽仅冷却对应 PAT 账号。当前请求未获得结果则换 PAT 重试当前账号；成功响应恰好耗尽额度则先保存结果，下一账号换 PAT。已完成账号不重复请求。
4. 所有可用 PAT 额度耗尽时等待最早可信恢复时间，支持取消、恢复；没有可信恢复时间则暂停并说明原因，不忙循环。
5. 二级限流、Retry-After 或无法确定性质的限制保持全局退避/暂停，不通过换账号持续重试。401 确认凭据无效后可切换有效凭据；网络失败有限重试，不能误记为账号失效。
6. 保存任务当前 PAT 标识用于状态展示和恢复，不将 token 写入任务状态。沿用现有有界 PAT 维护机制，不能因无额度反复创建 PAT。
7. 原有全局冷却若无法确定是普通配额还是二级限制，保留至到期；新记录明确冷却作用域。

## 检测配置弹窗

账号列表工具栏提供“检测设置”。沿用现有紧凑弹窗、校验、保存中反馈和成功后关闭交互。

- 检测状态：可用、失效、未知、未检测，多选；默认可用、未知、未检测，不选失效。
- 来源分组：全部或多选具体分组，支持未分组。
- 标签：全部或多选标签，支持无标签；同一维度内任一匹配，状态/分组/标签维度之间同时满足。
- 自动检测开关：默认关闭。
- 检测间隔：正整数天数（1–365），提供 1、3、7、15、30、90、365 天快捷值；初始建议 7 天。
- 底部预览符合范围数量及当前到期数量；保存与“检测此范围”区分，保存不开启额外手动检测。
- 若原来选定的分组/标签被删除，不能退化为全部账号；保留范围限制并提示修改规则。

手动单个/勾选检测是明确操作，允许立即复查，不受到期时间限制。新增“检测筛选结果”使用整个筛选结果，不限当前分页；“全部检测”仍明确代表所有非回收站账号。弹窗“检测此范围”使用弹窗已确认条件。自动检测只使用持久化配置，不受当前页面临时筛选影响。

## 到期判定与调度

- 到期：从未检测，或当前时间 >= checkedAt + 间隔天数。修改间隔不修改账号原检测时间。
- 未检测账号只有被配置选中时才纳入。回收站始终排除。
- 后端服务每分钟检查一次到期集合；没有符合账号则不请求 GitHub，也不准备 PAT。
- 关闭网页不影响后台服务；电脑/项目服务停止时无法运行，恢复启动后补查到期账号，不重复补跑错过的每个周期。
- 同时只运行一个检测任务。已有手动检测、未完成检查或冲突的 PAT/账号授权任务时顺延，不覆盖任务或抢占人工处理。手动取消后不在下一分钟立即重新启动同一自动批次。
- 保存规则时清楚区分启用与关闭。关闭自动检测停止未来调度，已运行任务通过现有取消按钮处理。
- 运行中每个账号请求前重新核对删除/身份/自动范围资格，避免删除或重新分组后仍被旧快照检测。
- 保留 checkedAt 的现有结果时间语义；额外持久化自动尝试时间、重试时间和连续失败次数，避免未知/网络失败账号每分钟重复请求。失败退避为 30 分钟、2 小时、6 小时，后续最多每 6 小时尝试；共享限流优先遵守服务器返回的恢复时间。
- 调度设置、下次重试和任务进度重启后保留。仅保存当前必要状态，不恢复通用操作历史表，不无限累积调度日志。

## 实现边界

- server/pat-service.js：随机选取、账号配额冷却、全局限流区分；与现有维护/验证机制衔接。
- server/checker.js：额度耗尽后从当前未完成账号接续；公开当前 PAT 用户名及切换/等待状态；复用检查点。
- 独立检测配置与调度模块：持久化设置、统一筛选、到期判断、互斥、失败退避和停止生命周期。
- server/app.js、server/index.js：配置/预览/手动范围接口及生产调度启停；测试环境可注入时钟和关闭定时器。
- src：检测设置弹窗、筛选检测入口、简短状态；不另加页面或常驻说明面板。

## 验证

使用临时数据库、可注入随机数和时钟、模拟 GitHub 响应，不消耗真实 PAT 配额或执行真实授权。

- 单个/批量任务随机选择；成功耗尽最后额度、403 普通额度耗尽均正确切换且不重查已完成账号。
- 全部额度不足等待最早恢复时间；二级限流不切换；无效、停用、过期 PAT 不被选用。
- 筛选组合、未分组/无标签、删除筛选项、零匹配以及跨分页范围正确。
- 每个账号独立按最近检测时间到期，包含未检测和排除失效，修改周期即时重算。
- 重启、失败退避、取消、手动任务冲突、调度开关及进度恢复不重复检测或覆盖任务。
- 桌面/移动弹窗、键盘操作、数值校验、保存成功关闭与失败保留输入。
