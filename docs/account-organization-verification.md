# 账号管理与紧凑界面验收（2026-10-19）

## 行为

- 来源分组为单选，默认未分组；用途标签为多选，最多 50 个。两者与公开检测、选用占用、PAT、WorkBuddy 任务分别保存。
- 分组、标签有独立管理页，支持新增、修改、删除、关联账号数量与跳转筛选；标签支持六种颜色。
- 导入、新增可指定来源和标签。已有账号可点击来源或详情中的「整理分类」；批量操作支持移动分组、追加标签、移除标签、替换全部标签。
- 删除分类只删除关联；删除分组后账号归入未分组，包含回收站中的账号。所有批量关联修改在事务内执行。
- 检测结果显示未检测、公开可访问、公开不可访问、无法判断（请求受限 / 检测失败）。不将 HTTP 404 或网络错误等同封号。
- 搜索覆盖用户名、邮箱、备注、用途、分组和标签。检测、分组、标签、TOTP 可组合筛选；切换筛选或账号离开当前结果后取消隐藏勾选。
- 每页可选 15 / 25 / 50 / 100 条，默认 25 条。桌面使用紧凑表格，手机使用账号卡片。
