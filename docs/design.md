# GitHub 账号工作台 · 第一阶段

本地单用户账号管理网页，React + TypeScript 前端、Node.js / Express 后端、SQLite 持久化。Node.js 最低 22.15（UI 测试使用内存 TSX 编译钩子）。只绑定 127.0.0.1；第一阶段不执行 GitHub 登录或 OAuth 授权。

## 范围

- 每行 `邮箱----密码----用户名[----TOTP密钥]`，粘贴和 UTF-8 TXT 文件，最多 1000 行 / 1 MB；预览行号及校验问题，不回显错误行中的秘密。
- 用户名和邮箱大小写不敏感去重；重复不覆盖原记录。没有 TOTP 可导入；密钥为 Base32。
- 搜索、状态筛选、分页、单个新增、单条编辑、备注、软删除及恢复；列表快捷检查 / 编辑 / 移除，支持批量移入回收站及批量恢复。
- 密码与 TOTP 使用 AES-256-GCM；密钥独立保存在 data/master.key。数据库备份需连同密钥；这不防范能读取整个 data 目录的人。
- GitHub GET /users/{username} 查询公开资料，200 为可访问、404 为不可访问、403/429 为限流或拒绝、超时/其他错误为未能判断。公开可访问不等于无风控或能登录。不再提供人工审核或人工风控标记。
- 单个、勾选批量、全部账号检查。全部检查从服务端读取账号库，不受前端筛选 / 分页影响，不含回收站，不限制为 1000 条。串行执行、进度条与分类计数、可取消后续请求，遇限流停止并显示剩余未检查数。记录结果和时间。
- 候选账号：24 小时内公开资料可访问、未选用。旧人工状态不再影响候选条件，数据库旧列不破坏性删除。选用在数据库事务内立即标记并记录时间和用途，防止重复；可以确认后手动释放。
- 列表不返回密码/密钥，详情显式读取，30 秒后隐藏；详情中的邮箱 / 用户名 / 密码 / 密钥只读且可分别复制；修改在独立编辑弹窗中完成，复制秘密无需先显示。详情支持读取、刷新及复制当前 TOTP 验证码与自动活性检测。
- 本地请求校验 Host、Origin 和自定义请求头，禁止跨站读写。无需云服务或远程账号管理后台。

## 视觉与交互

工具型中文工作台。浅蓝灰底 #f6f8fb、白色表面 #ffffff、墨蓝文字 #19273b、蓝色主操作 #315de6、青绿成功 #187458、琥珀警示 #9a640e。系统中文无衬线正文，Bahnschrift 标题，Consolas 数据。左侧紧凑导航，主区账户表格，顶部数量概览；详情与编辑使用不同用途的居中弹窗，桌面两列、手机单列。详情只读、编辑单独保存；固定底部反馈和操作。未保存修改、退出导入、释放标记均用站内二次确认弹窗，说明后果，提供明确取消和确认动作；Esc 只取消最上层确认。可访问性：键盘焦点、原生 dialog 焦点管理、错误提示、状态文字、减少动态效果；窄屏账户卡片。

## 验收

解析、去重、加密、TOTP 标准向量、GitHub 状态映射、持久化、原子选用、恢复和 HTTP 安全边界自动测试；生产构建；浏览器实际导入/详情/编辑/筛选/标记/恢复，375px 与桌面截图。测试数据使用临时目录，不混入用户数据。
